# 🏛️ NEXUS EXCHANGE (넥서스 증권거래소)

> 모든 자본과 기업이 교차하는 하이엔드 실시간 증권거래소 & 유저 기업공개(IPO) 플랫폼

---

## 🌟 특징
* **실시간 캔들스틱 차트 & 호가창**: 2.5초마다 살아 숨쉬는 실시간 주가 틱 엔진 및 10단계 매도/매수 호가창
* **기본 1호 상장사 `(주)자켓홀딩스(JARKET)`**: 처음부터 거래 가능한 공식 유통·엔터 지주회사
* **유저 기업공개 / 주식 상장 (IPO)**:
  * 50만 칩 자본금을 모은 유저는 누구나 자신의 기업을 증권거래소에 상장 가능!
  * 상장 즉시 **창업자 지분 30% 무상 지급**, 나머지 70%는 공모 시장에 공개
* **ONEID & 카지노/마트 자금 100% 연동**:
  * 슬롯머신에서 딴 돈으로 주식 풀매수, 주식 익절금으로 자켓마트 명품 쇼핑
* **자켓마트 증권 아이템 연동**:
  * 🧻 노브랜드 3겹 화장지 보유 시 손절 매도 손실금의 30% 위로금 환급
